# Caravel 产品介绍与功能说明

[English](product-overview.en.md) · **简体中文**

## 产品定位

**Caravel 是面向多项目、多任务开发者的本地优先多 AI 编码 Agent 指挥台。支持 macOS（Apple Silicon / Intel）与 Windows x64。**

Caravel 在两个平台均提供包含全部功能模块的通用版，沿用原有应用数据。macOS 与 Windows x64 均支持应用内签名更新；旧 Windows 客户端需先手动安装支持自动更新的版本。前往 [下载页面](https://github.com/yy36295238/caravel-releases/releases/latest) 选择对应系统的安装包，首次安装说明见 [官网安装帮助](https://caravel-site.pages.dev/#install-help)。

它将 Claude Code、Codex、OpenCode、pi、Grok、TRAE 等编码 Agent 集中到一个桌面工作台中，帮助用户统一派发任务、跟踪进度、处理授权、审查代码并完成交付。本机尚未安装的 Agent 可在设置里一键安装或升级。

Caravel 不替代 Agent、模型或代码编辑器。用户继续使用自己的 Agent CLI、模型账号和 IDE，Caravel 负责把分散的 Agent、项目、会话和代码改动组织成清晰、可控的任务工作流。

## 为什么需要 Caravel

只运行一两个 Agent 任务时，CLI 简单直接。但当用户同时维护多个项目、并行运行多个 Agent 后，终端和会话很快变得难以管理：不知道哪个任务还在运行、哪个正在等待确认、哪个会话属于哪个项目，也难以及时续接任务和统一验收代码。

用户不得不在脑中维护一张隐形表格：哪个终端对应哪个项目、使用哪个 Agent、正在做什么、是否需要介入、最后修改了哪些代码。真正的瓶颈从“Agent 能不能完成任务”，变成了“人能不能管理这些 Agent”。

Caravel 将原本散落在终端里的执行过程组织成可追踪的任务。一个任务包含目标、工作区、Agent、持续会话、运行状态和最终代码改动；用户在一个工作台中完成派发、监控、干预和验收，把注意力放在目标和决策上。

## 核心价值

- **统一管理**：在一个工作台中管理多个 Agent、项目和并行任务。
- **过程可见**：随时了解任务进度、Agent 动作、待处理事项和最终结果。
- **交付可控**：通过权限确认、代码审查和验收机制控制 Agent 对项目的影响。
- **经验复用**：把高质量提示词、技能、解决经验和成功流程沉淀为可复用资产。
- **持续改进**：通过成本洞察和 AI 复盘，发现协作问题并优化使用方式。
- **就地扩展**：用定时器、数据库、小应用把重复工作和常用工具留在同一工作台。

## 功能架构

| 层级 | 能力领域 | 核心作用 |
|---|---|---|
| 核心工作流 | 多 Agent 指挥、任务协作、安全交付、移动协同 | 管理从任务派发、过程干预到代码验收的完整链路 |
| 自动化与编排 | 定时自动化、工作流编排 | 将重复任务和复杂流程交给 Agent 按计划执行 |
| 经验与效能 | 提示词、技能、经验库、洞察台、复盘台 | 复用有效方法，衡量效果、成本和运行健康 |
| 配套开发工具 | 编辑器、数据库、待办、收件箱、剪贴板、我的应用 | 在同一工作台中完成常用开发与个人效率工作 |
| 设置与环境 | Agent、插件、模型、权限与本机维护 | 统一管理 Agent 运行所需的工具、能力和偏好 |

## 功能说明

### 1. 工作台

统一创建和管理多个 AI Agent 任务，可通过列表、看板或分屏实时查看进度。

筛选栏集中提供同步、视图和分屏操作，空间不足时收进「更多操作」。列表视图按 `⌘F`（Windows/Linux 为 `Ctrl+F`）打开当前会话查找栏，查看命中数量并用 `Enter / Shift+Enter` 定位，`Esc` 关闭并清除高亮；分屏查找当前焦点会话，工作台内嵌工作流同样支持。

- 统一管理 Claude Code、Codex、OpenCode、pi、Grok、TRAE；调用入口使用品牌图标、Agent 下拉与模型组合选择器，设置页保留完整启用管理
- 从对话、授权确认到计划、子 Agent 进展、代码 Diff 审查和最终交付，都在同一页面完成；计划卡片可在会话区域内拖动，支持方向键调整和 Home 复位
- 助手正文收到单条完整回复后再连续逐字呈现，按长度自适应字速；等待定稿时仍实时显示思考和工具活动。历史加载、同步和网页轮询记录直接完整展示，窗口恢复时直接展示已定稿正文
- 桌面已完成回复中的图片链接自动显示可放大的缩略图；聊天 SVG 可切换图片与只读源码，支持选择和复制源码
- 桌面已完成回复中的本地视频链接与可识别的行内代码路径显示视频缩略图，点击后在消息内从头播放，支持进度、音量和全屏；默认不自动播放，离开会话后停止，无法播放时可用外部程序打开；可直接打开视频所在目录，悬停文件名查看完整路径
- 桌面、手机聊天及工作流输出中的闭合 Mermaid 代码块可切换图表与文本、缩放；飞书对话快照也支持图表呈现，未闭合代码块保留源码
- 新建任务、继续对话和会话分叉可按次选择模型与推理强度，默认沿用模型设置；模型统一在 Agent 设置中维护，历史任务保留已有模型回显；任务标题显示最近一轮已知推理档，续聊沿用该档位且不会覆盖手动选择
- 向上阅读时自动加载更早消息并保留阅读位置，工作台快速预览与手机任务详情同样支持历史翻阅
- 任务轮数与活跃时长按完整会话统计，不受消息分页影响；活跃时长不包含轮间等待输入的空闲时间
- 自动生成任务标题可在「设置 → Agent → 通用配置」中开启，新老用户默认关闭；开启后，新任务的长描述由所选 Agent 和模型异步概括，不阻塞执行，桌面、网页和手机详情显示生成状态。关闭时保留原名称，尚未返回的概括结果不再用于改名；不回改已有任务，不影响手动「AI 生成」、完整目标或手动改名
- 任务可关联多个工作区，并汇总直接与间接相关任务；新建任务的关联工作区弹窗可对主仓库及关联仓库切换分支、提交、拉取与推送，操作作用于工作区原目录
- 新建独立分支任务可为多个 Git 项目分别建立副本，逐项目选择远程 main/master 基线和开发分支；任务项目面板可追加项目、查看接入状态、浏览文件和操作 Git
- 独立分支名可手填或由所选 Agent/模型结合任务内容、Jira 编号及指定技能规范生成，同时生成短任务名并用于创建任务和副本目录；生成期间修改输入不会被迟到结果覆盖，缺少必要信息时可补充或手填，实际分支在提交后创建
- AI 任务标题优先提炼核心动作与对象；新建独立分支的任务目录和项目子目录仅使用英文字母、数字及 `-_.`，空名称回退为 `workspace`，附加 ID 区分重名；任务目录的名称部分最多 20 字符，已有路径和完整任务目标保留
- 运行中追加的项目在下次运行接入，也可选择「暂停接入后继续」；多项目执行需要 Agent 或适配器支持附加工作目录
- 对话消息可复制为文本或图片，方便分享完整回复
- 桌面与完整网页端可点击删除图标，经确认后将误发的用户消息标记删除，取消不提交；保留带删除线的原文并提交一次纠正指令，请 Agent 忽略该消息及附件、等待后续输入；运行中须先停止，标记随历史同步保留，手机只读显示。不撤回原生历史或撤销已执行操作
- 启动和周期检查会校正进程已退出的运行中、待确认任务；明确中断的任务标为待续接，不自动续跑。Codex/TRAE 缺少本轮记录或明确终态时标为失败
- 重复续接以最新一次有效请求为准，自动取消旧运行及待回答问题，确认进程退出后恢复会话；同一任务按请求顺序切换，不同任务仍可并行
- 新建任务和继续对话支持从 Finder / 资源管理器复制文件后粘贴为附件，保留原文件名并去重；工作流、待办和收件箱复用相同附件能力；桌面右键菜单支持粘贴文本、图片和文件，附件只进入当前输入区域
- 可随时停止任务或转到终端继续处理；停止时回收该任务全部未结束运行的进程，未能退出时明确报错

#### 会话台

在「设置 → 功能管理」按需开启，默认关闭。无需先选项目，即可在固定会话工作区发起对话；所有会话共用该目录，与工作台、任务库中的普通任务分开展示，关闭入口不会删除历史。

- 发送首条消息时创建会话，支持 Agent、模型、推理强度、权限、附件、技能和任务引用，独立保留新会话草稿
- 按关键词、日期和标签查找，默认显示今天；支持置顶、收藏、标签管理、删除确认和历史会话直达
- 支持流式对话、授权处理、停止与续聊，显示用量、费用、耗时和轮数；列表宽度可拖动调整，窄窗口切换列表与聊天区

### 2. 任务库

集中保存和查找全部历史任务。

- 按状态、Agent、工作区、日期及是否有关联任务等条件筛选
- 支持搜索、收藏、归档和分组管理；普通、归档列表及分支关联任务可在当前页面弹窗查看完整详情，保留筛选、分页和列表位置，支持关闭按钮、背景及 Esc 退出
- 侧栏可按名称或路径搜索工作区，临时展开匹配分组，清空搜索后恢复原折叠状态
- 支持导入和同步已有 Agent 会话，统一纳入管理，包括 TRAE CLI 2.0 原生及官方迁移后的会话；Codex 兼容新旧会话记录，重建保留图片附件与回复评价，解析不完整或写入失败时保留原对话并独立校正运行状态；手动同步提示未完成的对话同步，历史运行不覆盖当前任务状态
- 同时提供工作区打开、Git 分支、提交、推送和冲突处理入口；本地副本缺失的独立分支仍可移除，已清理且目录不存在的项目隐藏，保留任务和恢复资料
- Diff 未保存上下文偏好时默认展示全文，仍记忆用户选择的精简或全文模式
- Git 支持只提交勾选文件，保留取消跟踪的删除操作和未勾选文件的暂存内容；任务头部直接显示分支及改动文件数
- 拉取远端更新时显示执行状态，完成后保留 Git 输出、文件及增删行统计、已是最新或失败原因，直到手动关闭；发现进行中的合并冲突时可进入解决器
- 提交弹窗直接展示模型选择与 AI 生成入口，生成提交文案后可编辑，再选择提交或提交并推送；默认采用带类型前缀的摘要，优先遵循补充说明中的格式要求。补充信息收起后仍保留，本机各仓库共用最近 20 条使用记录，可搜索复用，也可逐条删除历史项而不改变当前输入

### 3. 定时器

把每天、每周、每隔一段时间或只做一次的事交给它自动跑，不必自己守着点。

- **一句话创建**：用自然语言说出时间和要做什么，解析后回填表单让你确认，不会直接创建
- **也可手动填写**名称、内容和周期
- **周期**：每天、每周、每隔几分钟或几小时、只跑一次
- **多时刻**：每天或每周可设多个时刻，例如早上 9:30 和晚上 8:30 各跑一次
- **工作时段**：间隔任务可限制在指定工作日和工作时间内
- **三种执行方式**
  - 本地提醒：到点弹出提醒，不调用 Agent
  - 本地脚本：由 Agent 生成并试跑，之后按时执行本地脚本，不再重复调用 Agent；支持 shell 与 PowerShell
  - Agent 执行：到点按任务描述派发编码 Agent
- **错过补跑**：电脑当时没开时，可选择回来后补跑
- **立即运行**：不必等到点，可手动跑一次看效果
- **跑完处理**：可回看运行记录和产出，也可弹出提醒卡片
- **管理**：可暂停、编辑、删除；列表或卡片两种陈列，顶部显示下一次何时跑

### 4. 编辑器

浏览、搜索和编辑项目文件，减少在外部编辑器之间来回切换。

- 多标签页、语法高亮、自动保存
- 桌面编辑器支持 MP4、MOV、WebM、MKV、AVI 视频预览，按需读取本地文件；实际播放取决于系统编码支持，失败时可外部打开，网页和手机端保留文件信息提示
- Markdown（含内嵌 SVG 图像）、Mermaid 图表与图片预览，也可直接粘贴文件或目录路径打开
- SVG 文件速览默认显示图片，可切换只读源码；带行号的引用优先定位源码
- 查看、定位和回滚相对上次提交的改动；Diff 中可直接对照图片版本
- 文件速览可复制完整文件路径、打开完整 Diff，并使用常用 Git 操作；HTML 文件默认预览网页，可切换只读源码，带行号的引用优先定位源码。预览支持内嵌样式、脚本和数据资源；桌面端还可加载当前目录及子目录的 CSS、JS、图片、字体和媒体，单资源限 20 MiB，关闭或切换预览后撤销访问。仍隔离宿主权限，不加载目录外或远程资源、不发送接口请求；网页端仅支持内嵌资源；Diff 文件树支持折叠目录
- 工作区文件弹窗可选择已安装的外部编辑器并打开当前浏览目录，记住编辑器偏好；支持主工作区、关联目录与独立副本

### 5. 数据库

连接 MySQL、PostgreSQL、SQLite、MongoDB 或 Redis 后，在工作台里查数和改数。

- 浏览对象、筛选分页数据；SQLite 连本地文件，MongoDB 查文档，Redis 管 Key
- 编写和执行 SQL 或文档查询，查看、编辑或全量导出结果，结果也可导出为 SQL；可编辑结果的单元格与行详情值弹窗支持编辑原文、设置 NULL 和暂存修改，再由结果区统一确认提交
- 结果表支持拖拽或用键盘调整列宽，隐藏列和横向滚动仍按原字段定位
- 连续对话式 SQL Copilot 可统一生成、解释、优化和修复语句；普通提问默认不引用编辑器 SQL，可显式引用选区或当前语句，生成中可终止请求；同一窗口内切换功能、关闭面板或切换数据库后继续后台执行，返回原作用域可查看进度、结果及终止请求，同一作用域运行中防止重复提交，不同作用域分别执行；后台执行限当前窗口存活期间
- SQL Copilot 可按连接与数据库作用域记住关联工作区，让所选 Agent 自主检索当前磁盘代码（含未提交修改），结合表结构追踪业务逻辑，并查看引用的文件与行号；不发送查询结果，切换或取消关联后不再发送旧工作区的代码回答。分析沿用各 Agent 原生权限和项目配置，不提供统一沙箱保证；代码版本可能与数据库环境不同
- 连接配置按基本信息、连接、安全策略和高级选项分区，支持密码显隐及常驻测试结果；网络连接启用生产标记后自动锁定强制 TLS
- 支持收藏查询、参数化执行、执行历史和对象定义
- 可通过 MCP 把数据库能力交给 Agent
- 生产库危险操作会先确认，变更前能看到目标表规模
- 连接密码加密失败时拒绝保存，密钥异常时不会自动覆盖原密钥
- 连接列表可折叠；Redis 完整 Key 直接查询，通配搜索支持按游标继续扫描，明确区分扫描尚未结束与没有匹配结果；类型筛选兼容 Redis 6 之前版本

### 6. 待办板、收件箱与剪贴板

个人事项和随手材料不用另开应用。

- **待办板**：待处理、进行中、已完成三种状态；支持标签、有效期、子待办、图片和附件；待办可一键转为 AI 任务，并自动跟随任务完成
- **收件箱**：随手记录暂时不需要整理的想法、问题和资料，可加标签、图片和文件
- **剪贴板**：自动记录文本、代码、JSON 和图片历史，支持搜索、分类、收藏和常用片段；macOS 仅在剪贴板变化后采集并跳过文件引用，主动粘贴图片和添加附件不受影响

### 7. 提示词、技能与经验库

把有效的指令、工具和避坑经验留下来，下次直接用。

- **提示词**：分组管理，支持变量、置顶以及预绑定技能和 MCP；创建任务或继续对话时可用按钮或 `/` 命令插入
- 提示词库可搜索标题、正文、别名和分组，结合分组导航筛选；点击标题即可编辑，在分组内新建时自动沿用当前分组
- **技能与 MCP**：为任务组合专业能力和外部工具；技能依赖的 MCP 会自动带入任务和工作流
- **经验沉淀**：复盘仍可保存解决方法、适用场景和避坑规则；侧栏及功能管理不再提供独立的经验库入口，已有经验数据保留

### 8. 工作流

把 Agent 执行、命令操作和人工确认编排成可重复运行的流程。

- 为不同步骤指定角色、模型、技能和任务要求
- 支持变量、自动推进、人工确认、失败重试、步骤跳转和运行中止；已终止流程可重置任意步骤（含当前步），保留任务与代码，确认后展示目标步，点击「开始本步」恢复执行
- 当前 Agent 步暂停或完成待确认时，可按本步配置重新执行，保留任务、已有代码与其他步骤状态并更新本步产出；执行中不能重复启动
- 可将现有任务接入工作流继续推进
- 可从一次成功的 Agent 对话中提炼可复用工作流
- 保留运行记录，方便回看每次执行；任务状态旁显示当前步骤与步数，点击工作流入口，在不挤压会话的浮层中查看完整步骤、输入输出、运行统计并操作流程
- 工作台内嵌的工作流会话支持查找文字、查看命中数量并逐项定位

### 9. 洞察台与复盘台

不只记录 Agent 做了什么，还帮助判断是否有效、花了多少钱、下次怎么改。

- **洞察台**：查看任务效率、Agent 与模型表现、工具使用、成本与用量、权限安全和运行健康；每次进入默认打开「Agent 分析 → 成本与资源」，日期为本周一至今天，保留工作区、Agent 和趋势粒度偏好
- 成本可按金额或 Token 对比上一周期，并按 Agent、模型、工作区或标签下钻；高耗榜按任务汇总当前筛选内的多次运行，可查看用量明细并打开原任务
- 显示支持的账号额度与重置时间；TRAE 周额度依赖企业接口，接口不可用时显示错误或旧快照
- 运行健康可分 Agent 查看安装、数据、内存和 CPU 占用；TRAE 只统计 CLI 数据，不包含其它 IDE 数据
- **复盘台**：按时间、工作区和标签汇总多项任务，由 AI 生成带证据的成果、问题和下一步建议
- 报告可导出，也可把结论沉淀为提示词、经验、工作流或技能
- 对单条回复点赞或点踩，按模型汇总好评率

### 10. 我的应用

把个人常用小工具留在同一个工作台里。

- 用一句话描述想要的小工具，AI 就能把它做出来，例如日报助手或数据看板
- 创建或改进应用时可选择「跟随 Caravel」或「独立设计」，分别使用宿主主题或自定配色、字体、布局和控件；设置按应用保存，在下一次生成或改进时使用，不立即改变已有页面
- 也可以把网址或本地网页添加为链接应用，在窗口内直接打开
- 应用可以联网取数、读写你选中的文件、发通知或查看任务，用之前都会先征求同意
- 获得 AI 授权的应用可独立选择已安装且启用的 Agent 和模型，进行问答、结构化生成或流式输出，可自定义选择控件或嵌入宿主同款组件；不指定时跟随全局默认，选择失效时提示重新选择，不自动换用其他 Agent
- 桌面小应用经授权可运行本机程序或自带脚本，读取输出、发送输入并管理持续任务；还可查询系统环境、进程及单个进程的 TCP 监听端口，分别请求正常停止或强制结束指定进程
- 文件与目录按读写范围分别授权，支持列举、新建、移动、永久删除、文本与二进制、分段读取和原子替换写入；本地通信支持按回环地址与端口或 Unix Socket 路径授权
- 本机能力支持本次会话或记住授权，可在应用设置逐项立即撤销；安装不会自动授予本机访问权，授权不随分享包导出，网页与手机远程入口不开放这些接口
- 本机执行具有当前用户权限，不受文件和通信接口的范围限制，不能视为进程沙箱；关闭、刷新或撤销执行权会清理本会话直接启动的进程，不包括派生进程。Windows 不支持通用正常停止和 Unix Socket 接口
- 卡片、紧凑和列表视图按实际任务状态显示生成、改进、等待确认、中断及完成待安装，未安装草稿不再持续显示为生成中
- 私有存储和数据库操作需授权，限制跨库文件访问、长查询、并发及结果大小；网络跨源跳转需重新请求并授权，过大响应会截断
- 做好后可以继续改进、保存版本、导出分享

### 11. 独立分支与安全交付

把“Agent 能执行”与“代码可交付”分开。Agent 可以自主完成工作，但关键权限和最终代码仍由用户决定。

- 支持在隔离副本中完成代码修改，避免直接影响原项目
- 在工作区查看独立分支改动、浏览副本文件，并安全移除本地副本；提交和推送通过项目 Git 菜单操作，任务顶部不再提供独立分支的交付或放弃按钮
- 副本库中可清理已结束且无风险的隔离副本，任务与远程分支保留供续接
- 多项目独立分支任务汇总各仓库改动，可逐项目或统一提交推送；部分推送失败时保留成功成果，未提交或未推送成果仍需验收
- 解除关联仅停止项目参与后续运行，副本与成果保留；删除独立分支任务也会保留副本，新版副本可通过「接续开发」创建新任务并建立新会话
- 清理单个项目副本前检查未提交文件和远程提交状态，保留恢复信息；续接时在原路径恢复，远程成果分支已删除时明确提示，并可在清理后选择从主干新建分支
- 旧版独立分支任务保留原目录与关联方式，使用多项目隔离需新建任务；新版独立项目任务不支持分叉共用可写副本
- 对敏感操作发起授权确认，用户可选择单次或持续放行
- 集中展示代码变更，验收通过后再合并，不符合预期时可直接放弃

### 12. 设置

集中管理偏好与运行环境。

- **Agent**：通用配置集中管理默认 Agent、权限、运行方式、自动标题和静默超时，各 Agent 详情管理启用状态、模型和连接方式；浏览配置不会改变默认 Agent。模型编辑支持统一保存或撤销，切换配置目录保留未保存内容；从 CLI 检测后，未列出的已有模型标记为「未检测到」，不代表不可用，可保留或批量移除后保存。Codex 从本机 CLI 完整读取模型目录、显示名和各模型支持的推理档位，设置页与任务调用入口优先使用检测到的档位；检测失败或目录为空时提示错误，不据此标记已有模型缺失
- **Claude 连接**：保留稳定 CLI 与实验性 ACP，统一使用本机原生 `claude` 命令；不再提供 `reclaude` 启动选项，旧启动命令偏好不再生效
- **Codex 传输**：默认 App Server，保留已有 CLI/ACP 选择，切换只影响后续轮次。App Server 支持续接、分叉、授权卡、输入表单和运行中补充；异步问题允许 Agent 继续执行，轮次结束后保留表单，回答后按原权限继续。表单收到驱动确认后才撤下，失败可重试，并防止重复提交。标准模式可写工作区并按需授权，规划模式只读；CLI 无实时审批和运行中补充，标准/规划模式只读，分叉依赖本机版本。Fast 仅适用于 ACP
- **TRAE**：需要本机 CLI 2.0 与企业版旗舰版账号；检测账号可用模型及推理档，接入任务、工作流、定时任务和 AI 辅助调用；图片、多目录、分叉和运行中补充按 CLI 能力开放
- **安装与配套工具**：汇总已就绪、可升级和未安装数量，将需要安装、升级、处理错误或完成安装器的项目优先展示，集中查看版本和安装来源；一键安装或升级本机 Agent，以及 Git、Node、cc-switch 等配套工具；升级会识别并沿用当前安装来源，操作后核对可运行版本；显示当前阶段和明确标注的估算百分比（不代表下载比例或剩余时间），以及实际批量处理进度，切换菜单后保留任务、队列和安装器提示；图形安装器需完成安装后刷新，批量升级会分别提示完成、待手动完成与失败结果；macOS 通过 Homebrew 安装或升级 CC Switch 时优先使用官方镜像缓存同版本安装包，校验 SHA-256 后安装，镜像不可用则回退 Homebrew 下载
- **插件**：统一管理 Claude、Codex、OpenCode 与 TRAE 插件，并在任务中选用；按各 Agent 实际安装版本检查有独立 GitHub 仓库的插件正式更新，可打开发布页查看；未检查项可展开查看插件、Agent 和原因，不视为已是最新，不自动覆盖安装内容
- **默认终端**：选择打开终端或接管 Agent 时使用的终端
- **macOS 主窗口**：页面内容延伸至顶部，保留原生窗口按钮；拖动页面标题栏、工作台筛选栏或侧栏空白移动窗口，双击切换最大化；原生背景和明暗外观随应用主题同步
- **界面外观**：切换主题（含「夜航」深色与「晨航」浅色配色）、任务状态动效和界面缩放（80%、90%、100%、110%、125%、150%，默认 100%）；界面语言支持简体中文、英文或跟随系统，桌面多窗口同步，浏览器和手机分别保存偏好；未设置语言时继续使用中文，用户正文、代码和历史记录保留原文
- **语言覆盖**：工作台、Git、编辑器、数据库、工作流、定时器、个人工具、洞察与复盘，以及托盘、固定工具窗口标题、通知和飞书遥控文案；应用自有 AI 辅助生成默认采用界面语言，优先遵循用户明确指定的语言
- **异常恢复**：页面加载、渲染或启动失败时提供重试或重新加载入口；主窗口可返回首页，工具窗恢复当前页面。操作异常保留当前界面，技术原因与堆栈写入服务日志，不弹出全局错误提示。Rust panic 保存本地报告，下次启动静默归档；不包含系统强制终止或 WebView 原生崩溃。重新加载前需保存未提交的输入
- **功能管理**：控制左侧各功能入口是否显示，并支持拖拽排序；洞察台默认开启，副本库默认关闭
- **技能管理**：查看不同 Agent 的技能、声明版本与 MCP；可手动检查安装记录中的飞书官方版本和 GitHub 技能目录变化，未纳管、无可靠来源或固定引用等未检查项单独统计，可展开查看名称和原因，不视为已是最新，不自动覆盖本地内容；TRAE 支持全局技能和原生 stdio/HTTP MCP 管理，任务级 SSE 通过代理连接
- **远程控制**：配置飞书连接、智能对话和消息记录
- **浏览器访问**：完整网页端与手机只读端可独立开关；关闭其中一端不影响另一端，应用重启后恢复已开启的访问方式
- **软件更新**：macOS 与 Windows x64 支持应用内签名更新，显示下载百分比及安装阶段；Windows 按独立已交付清单检查版本，安装时退出应用并交给 NSIS；macOS 支持系统代理及更新后重启。手动更新与启动自动更新共享进度，切换菜单后继续显示；失败时可打开浏览器下载页
- **开发实例**：开发版与安装版可同时运行，各自保持单实例，使用独立应用数据与服务端口，以 DEV 图标和窗口、托盘标记区分；Agent 登录、工具配置与显式选择的工作目录仍共用
- **环境维护**：检查更新、查看运行环境和服务日志
- **副本库**：独立侧栏入口，默认关闭，可在功能管理中开启和排序；仅显示仍在磁盘上的副本，默认按任务分组，也可按项目分组，显示工作区名称及任务标签，支持搜索、重新扫描、跳转任务和安全清理；已清理项目的恢复信息保留在任务中，缺少恢复信息的目录不会自动清理

### 13. 飞书远程协同

离开电脑时，仍可通过飞书查看任务进展并处理关键节点，无需配置公网地址。

- 查看任务状态和 Agent 进度
- 创建任务和继续对话
- 处理权限确认与任务验收
- 接收关键状态通知

## 典型使用流程

1. 在设置中安装需要的 Agent，选择项目，描述目标，并指定合适的 Agent。
2. Agent 开始执行，用户在工作台统一查看多个任务的进度。
3. 遇到敏感操作或需要决策时，Caravel 提醒用户确认。
4. Agent 完成后，用户集中审查代码变更并决定合并、继续修改或放弃。
5. 将有效的提示词、解决经验或任务流程沉淀为提示词、经验或工作流。
6. 重复事项交给定时器：一句话说清时间和做法，确认后按时自动跑。
7. 通过复盘与成本洞察持续优化后续的人机协作方式。
8. 需要个人小工具或常用网页时，用「我的应用」生成或添加。

## 适用场景

- 同时使用多个 AI 编码 Agent 的个人开发者
- 需要并行推进多个项目或编码任务的工程师
- 希望让 Agent 自主执行、同时保留代码控制权的用户
- 需要反复执行代码检查、问题修复或发布流程的开发者
- 希望沉淀个人提示词、经验和 AI 协作方法的重度用户
- 关注 Agent 效率、成本和交付质量的技术负责人
- 需要定时提醒、本地脚本、数据库操作或个人小工具，又不想离开工作台的用户

## 产品特点

### 本地优先

任务、对话记录、工作区信息和个人知识资产由本机应用统一管理。用户掌握自己的项目数据，并自主决定是否启用飞书等远程能力。

### Agent 开放

Caravel 不绑定单一 Agent。用户可以根据模型能力、任务类型和使用习惯选择不同工具，在设置中安装或升级，并在统一的产品体验中管理它们。

### 人负责决策，Agent 负责执行

Caravel 的重点不是让 Agent 完全取代开发者，而是把人从重复执行中释放出来，同时保留目标设定、权限判断、代码审查和最终验收等关键决策权。

## 一句话总结

**Caravel 让多个 AI 编码 Agent 从分散的命令行工具，变成可统一指挥、可安全验收、可持续复用的开发生产力。**
